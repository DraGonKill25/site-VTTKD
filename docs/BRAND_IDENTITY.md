# Identité de marque — VAN THUYNE TAEKWONDO / ELITE

**Version :** revue finale de Phase 2, 7 novembre 2026  
**Statut :** proposition post-maquette, à valider par le club

## 1. Objet

Ce document rassemble uniquement les éléments visuels vérifiables et propose
une direction web cohérente. Il ne remplace pas une charte officielle et
n’autorise aucune modification du logo.

Sources observées :

- `logo.jpg` fourni dans le projet ;
- avatar du compte Instagram présenté comme officiel dans le cahier des
  charges, `@vanthuynetkd_officiel` ;
- avatar et bannière de la chaîne YouTube présentée comme officielle dans le
  cahier des charges.

La propriété de ces comptes par le club doit encore être confirmée par un
responsable autorisé.

L’accès aux publications Instagram étant limité, aucune conclusion n’est tirée
sur les affiches ou publications qui n’ont pas pu être consultées.

## 2. Statut des éléments

### 2.1 Éléments confirmés dans les ressources fournies

Ces constats sont vérifiables dans `logo.jpg`, mais ne constituent pas encore
une charte officielle :

- fichier JPEG carré de 160 × 160 pixels ;
- emblème circulaire à dominante bleu nuit et blanche ;
- symbole yin-yang, silhouettes de taekwondo et mentions visibles ;
- cohérence visuelle observée avec les avatars des comptes sociaux indiqués par
  le cahier des charges.

### 2.2 Éléments provisoires proposés pour les maquettes

- palette web issue d’un échantillonnage du JPEG ;
- accent orange doré ;
- concept « Maîtrise en mouvement » ;
- Barlow Condensed pour les titres et Inter pour le texte ;
- formes, grilles, rayons, iconographie et composants ;
- priorité visuelle au Kyorugi avec une présentation complète du Poomsae.

Ces éléments ne sont pas l’identité officielle du club.

### 2.3 Éléments nécessitant une validation du club

- forme officielle du nom et usage de « ELITE » et « GENTILLY » ;
- couleurs et références colorimétriques officielles ;
- typographies officielles ou validation des polices proposées ;
- concept et accent chaud ;
- règles d’utilisation du logo ;
- photographies, vidéos, crédits et autorisations ;
- propriétaires et droits des ressources graphiques ;
- version vectorielle, variantes et favicon.

Tant que ces éléments ne sont pas validés, les maquettes restent des
propositions réversibles.

## 3. Logo vérifié

### 3.1 Composition

Le fichier disponible présente :

- un emblème circulaire ;
- une bordure extérieure double ;
- la mention supérieure « VAN THUYNE TKD » ;
- la mention inférieure « CLUB ELITE » ;
- la localisation « GENTILLY » ;
- un symbole yin-yang central ;
- deux silhouettes de taekwondo en partie basse ;
- une composition bleu nuit et blanche.

La construction évoque simultanément la tradition martiale, la discipline, le
mouvement et l’identité locale.

### 3.2 Fichier disponible

- Nom : `logo.jpg`
- Format : JPEG
- Dimensions : 160 × 160 pixels
- Fond : intégré à l’image
- Transparence : aucune
- Utilisation adaptée : audit, référence et petit aperçu provisoire
- Utilisation déconseillée : hero, impression, très haute densité, détourage ou
  favicon définitive

### 3.3 Règles provisoires d’utilisation

En attendant les originaux :

- ne pas redessiner le symbole ;
- ne pas modifier les textes ;
- ne pas étirer ni incliner le logo ;
- ne pas recolorer les éléments ;
- ne pas ajouter d’effets, ombres ou contours ;
- conserver un espace libre d’au moins 20 % du diamètre autour du sceau ;
- éviter une taille d’affichage inférieure à 48 pixels ;
- ne pas utiliser le JPEG disponible pour produire un grand visuel ;
- employer un libellé texte séparé si le nom doit rester lisible en petit.

### 3.4 Fichiers officiels à demander

- SVG ou fichier vectoriel source ;
- PNG transparent en haute définition ;
- version monochrome approuvée ;
- version pour fond sombre et pour fond clair ;
- éventuelle version horizontale ;
- favicon ou symbole simplifié officiellement validé ;
- règles d’espacement et de taille minimale ;
- coordonnées du propriétaire des droits.

Une conversion automatique du JPEG en SVG ne constitue pas un original
officiel.

## 4. Couleurs

### 4.1 Couleurs observées

Le logo raster permet d’identifier deux familles dominantes :

- bleu nuit très sombre ;
- blanc légèrement cassé.

Un échantillonnage indicatif du raster donne environ :

- **Bleu nuit provisoire :** `#04042E`
- **Blanc provisoire :** `#F9F9FA`

Ces valeurs sont des mesures techniques sur une image compressée, pas des
références officielles. Elles pourront varier avec le fichier vectoriel.

### 4.2 Accent chaud

La bannière YouTube observée utilise un fond orange soutenu associé à des
photographies sportives. Cet orange peut inspirer un accent web pour les appels
à l’action, les échéances et certaines statistiques.

Il ne doit pas être déclaré couleur officielle avant validation des supports
originaux. Une seule teinte d’accent devra être retenue après test de contraste.

### 4.3 Système de couleurs recommandé

Le futur système devra utiliser des rôles, et non des couleurs dispersées :

- `brand-primary` : bleu nuit validé ;
- `brand-on-primary` : texte clair ;
- `brand-accent` : accent chaud validé ;
- `surface` et `surface-muted` : fonds de lecture ;
- `text` et `text-muted` : textes ;
- `border` : séparateurs ;
- `success`, `warning`, `error` : états fonctionnels ;
- `medal-gold`, `medal-silver`, `medal-bronze` : podiums.

Les couleurs de médaille servent uniquement aux résultats. Elles ne deviennent
pas des couleurs principales de marque.

### 4.4 Accessibilité

- Tous les couples texte/fond devront respecter WCAG 2.2 AA.
- Une information ne reposera jamais uniquement sur une couleur.
- Les états de focus seront visibles sur fond clair et sombre.
- L’accent chaud ne sera utilisé pour du texte que si le contraste est
  suffisant.
- Les podiums associeront couleur, libellé et position.

## 5. Typographie

### 5.1 Constat

Le nom du club dans le sceau utilise des capitales avec empattements. La
résolution actuelle ne permet pas d’identifier la police avec certitude.
La typographie du logo fait partie du dessin et ne doit pas être imitée
approximativement pour les textes du site.

### 5.2 Proposition web

Sous réserve de validation :

- **Titres et chiffres sportifs :** Barlow Condensed, graisse 600 ou 700.
- **Texte courant et interface :** Inter, graisse 400 à 700.
- **Repli système :** familles sans serif disponibles localement.

Raisons :

- licences ouvertes et hébergement local possible ;
- excellente lisibilité sur mobile ;
- titres compacts adaptés aux résultats et calendriers ;
- chiffres clairs pour classements et dates ;
- bonne couverture du français et de l’anglais.

### 5.3 Alternative

Une famille unique variable comme **Roboto Condensed** peut réduire le nombre
de fichiers et simplifier la maintenance, au prix d’une identité plus neutre.

Le choix final devra être testé sur les mots longs anglais, les accents français
et les très petits écrans.

### 5.4 Règles typographiques

- Un seul titre principal par page.
- Capitales réservées aux titres courts, catégories et statistiques.
- Aucun paragraphe long entièrement en capitales.
- Longueur de ligne cible de 55 à 75 caractères.
- Interlignage généreux pour les contenus éditoriaux.
- Chiffres tabulaires pour les tableaux et listes de résultats.

## 6. Photographie et vidéo

### 6.1 Direction photographique

Priorité aux images authentiques du club :

- actions de compétition ;
- préparation et concentration ;
- portraits autorisés ;
- équipes et encadrement ;
- podiums ;
- entraînement Combat et Poomsae ;
- gestes techniques et détails d’équipement.

Les deux disciplines doivent recevoir une qualité et une visibilité
comparables.

### 6.2 Traitement recommandé

- cadrage immersif mais respectueux du sujet ;
- colorimétrie cohérente d’une page à l’autre ;
- priorité au sujet plutôt qu’aux effets ;
- superposition de texte uniquement sur une zone dont le contraste est
  garanti ;
- formats AVIF et WebP générés automatiquement ;
- dimensions adaptées au contexte ;
- légende et crédit lorsque nécessaires ;
- texte alternatif décrivant le contenu utile.

### 6.3 Traitements à éviter

- filtres excessifs ;
- détourage artificiel systématique ;
- faux effets de vitesse ;
- collages surchargés ;
- photos génériques de banque d’images présentées comme le club ;
- miniatures YouTube chargées avec le lecteur complet hors écran ;
- médias sans preuve de droit de publication.

## 7. Éléments graphiques

### 7.1 Éléments compatibles avec l’identité

- cercles et arcs inspirés du sceau ;
- lignes de trajectoire très discrètes ;
- cadrages diagonaux limités aux zones sportives ;
- grands numéros pour résultats et dates ;
- grilles éditoriales nettes ;
- séparateurs fins et contrastés.

Ces motifs doivent rester secondaires. Le yin-yang et les silhouettes ne seront
pas extraits ou recomposés sans fichier source et autorisation.

### 7.2 Iconographie

- style linéaire simple ;
- épaisseur cohérente ;
- icônes toujours accompagnées d’un libellé si le sens n’est pas universel ;
- aucune icône décorative ajoutée uniquement pour remplir l’espace.

## 8. Direction artistique proposée

### 8.1 Concept

**« Maîtrise en mouvement »**

Le site associe :

- la stabilité du bleu nuit ;
- la précision du blanc ;
- une impulsion chaude pour les actions importantes ;
- des images de compétition à forte présence ;
- une mise en page structurée qui évoque la préparation et la performance.

### 8.2 Page d’accueil

- Hero photographique avec logo non déformé, nom du club et message court.
- Accès immédiat aux derniers résultats et au calendrier.
- Entrée principale vers le Kyorugi et entrée complète vers le Poomsae.
- Bloc palmarès calculé, sans chiffres provisoires présentés comme réels.
- Actualités et vidéos sélectionnées manuellement.
- Réseaux sociaux présentés comme liens, sans flux lourd ni tracker tiers.

### 8.3 Résultats

- compétition, date et lieu en tête ;
- filtres accessibles ;
- podiums lisibles et sobres ;
- discipline explicitement indiquée ;
- cartes ou lignes compactes sur mobile ;
- détail complet disponible sans interaction cachée.

### 8.4 Fiches athlètes

- photographie uniquement si autorisée ;
- nom affiché et discipline ;
- catégorie sportive sans donnée personnelle inutile ;
- parcours éditorial ;
- résultats calculés depuis les données publiées ;
- option de ne pas publier le profil.

## 9. Mouvement et interactions

- Transitions de 150 à 250 ms pour les interactions simples.
- Aucun mouvement indispensable à la compréhension.
- Pas d’autoplay vidéo ou audio.
- Pas de parallaxe lourde.
- Respect de `prefers-reduced-motion`.
- États de survol doublés d’états clavier.
- Les filtres et menus restent utilisables sans animation.

## 10. Responsive

### Mobile

- navigation compacte et accessible ;
- filtres ouvrables sans masquer le contexte ;
- résultats lisibles sans défilement horizontal ;
- images recadrées avec point focal documenté ;
- appels à l’action facilement activables au toucher.

### Tablette

- administration utilisable en orientation paysage ;
- grilles de deux colonnes selon la longueur des contenus ;
- aperçu des médias sans surcharger l’écran.

### Grand écran

- largeur de lecture limitée ;
- photographies plus immersives ;
- espace blanc assumé ;
- aucune simple mise à l’échelle disproportionnée du mobile.

## 11. Voix éditoriale

Le ton recommandé est :

- direct ;
- factuel ;
- ambitieux sans exagération ;
- respectueux de tous les niveaux et disciplines ;
- précis sur les dates, catégories et résultats.

À éviter :

- superlatifs non prouvés ;
- résultats sans source ;
- formulations qui minorent le Poomsae ;
- promesses sportives ;
- jargon non expliqué ;
- traduction automatique publiée sans validation.
